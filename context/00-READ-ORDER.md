# Read order

Read these in order on first run, then only what a task needs. Total read time for Hermes on first boot: all ten files, once. Then `BACKLOG.md` at the repo root, which is the discretionary work list.

| # | File | What it gives you | Read when |
|---|------|-------------------|-----------|
| 01 | `01-deep-flow-lineage.md` | Where Deep Flow came from, the two earlier versions, what carried over and what was dropped, with the reasoning | First boot, and before any brand or positioning work |
| 02 | `02-brand-foundation.md` | What is fixed about the Deep Flow brand and what Sreekar still decides | Any content, design, or copy task |
| 03 | `03-the-stable-and-the-flow-arts-scene.md` | The stable, the flow arts community in Bangalore, partner shortlist, open questions | Events, outreach, partnerships, community |
| 04 | `04-champions-group-light.md` | Champions Club, Champions Ranch, 100X Longevity, who is who | Any task that touches the group. Keep it light until Sreekar's scope there is confirmed |
| 05 | `05-decisions.md` | Decision log with reasoning (Hermes over Paperclip, Telegram first, free tiers for loops, and so on) | Before proposing a change to the setup |
| 06 | `06-operating-policy.md` | Act, ask, never. Who Hermes serves and who it escalates to | First boot, then whenever unsure whether to act |
| 07 | `07-domain-site-and-stack.md` | deepf1ow.com, Namecheap, Cloudflare, how pages get built and deployed | Any site or landing page work |
| 08 | `08-model-strategy.md` | Free tiers for the daily loops, a mid tier model for hard work, how to route | Setup, and whenever a run hits a rate limit |
| 09 | `09-people.md` | Sreekar, Champ, and the names that come up | Drafting anything that names a person |
| 10 | `10-connectors-and-tools.md` | What Flow is wired to, what to add later and how | Setup, and before proposing any new tool or MCP server |

Rules for this folder:

- These files are the memory that does not fit in `MEMORY.md`. Quote from them, do not paraphrase brand rules.
- When a fact here changes, update the file and add a line to `05-decisions.md`. Do not keep two versions alive.
- No em dashes or en dashes anywhere in this repo. The check script enforces it.
